Sunseed — a light-routing garden puzzle game. Route sunlight through mirrors to wake the seeds: every seed you grow changes the light path, opening the way to the next. Three hand-built levels, undo, procedural WebAudio sound, no external files.

## Run it

```sh
node serve.ts
```

Serves `game/` on http://localhost:8080 — open it in a browser and play.
