Tidegate — a water-routing garden puzzle game. Turn one rotary diverter gate to send a limited reservoir through three increasingly tricky layouts. Bloom every bed before the water runs out; water sent to the drain is wasted. Three hand-built levels, undo, live flowing water, and no external files or dependencies.

## Run it

```sh
node serve.ts
```

Serves `game/` on http://localhost:8080 — open it in a browser and play. Start with the title screen, then use the gold wheel, Space, or arrow keys to route water. `U` undoes the last turn and `R` restarts the level.
